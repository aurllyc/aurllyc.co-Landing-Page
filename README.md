# aurllyc.co — Landing Page Wireframe

Landing page modern dan clean untuk brand design studio **aurllyc.co**.
Dibuat menggunakan HTML, CSS, dan sedikit JavaScript vanilla untuk interaksi FAQ.

---

# ✦ Tentang Project

Project ini merupakan wireframe landing page dengan konsep:

* Clean & minimal
* Warm white aesthetic
* Editorial modern
* Premium visual
* Responsive layout
* Fokus pada branding dan portfolio

Landing page ini dirancang untuk menampilkan:

* Hero section
* About brand
* Services
* Portfolio showcase
* Testimonials
* Pricing
* FAQ
* CTA section
* Footer

---

# ✦ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript

Tanpa framework. Karena kadang manusia merasa “ngoding manual biar lebih fleksibel”, lalu 4 jam kemudian debugging margin.
